Check for RasCAL-2 Updates
--------------------------
RasCAL-2 automatically checks for updates when the software is opened. You can manually check for update by clicking
**Help > Check for Update** in the main menu

After an update check, the software will notify the user if a new release is available and provide a hyperlink to
download the installer for the new version.

.. image:: /images/update_dialog.png
   :scale: 80
   :alt: Update Dialog showing Successful Check
   :align: center

.. note:: You can also stop the automatic update checks by unchecking the **Check for updates on startup** checkbox.

Report Issues
-------------
When reporting a bug or crash, it is important to report the version of RasCAL-2 and provide the software logs so it is
easier to replicate and fix the issue. These information are present in the about dialog which can be opened by clicking
**Help > About** in the main menu.

.. image:: /images/about_dialog.png
   :scale: 80
   :alt: About Dialog
   :align: center

Exiting RasCAL-2
----------------
RasCAL-2 can be closed by clicking the **File > Exit** on the main menu in the software. If the current rasCAL-2 project
has been modified or has unsaved results, a message will pop up to prompt saving the Project. Press the **Save** button
to specify saving the project, the **Discard** button to specify not saving the project, or Cancel to abort the
operation and return to the software.

.. image:: /images/unsaved_changes_dialog.png
   :scale: 80
   :alt: Unsaved Changes Dialog
   :align: center

.. note:: This dialog could look slightly different on linux or macOS.
