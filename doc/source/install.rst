
Installation
============
This section provides more detailed information about installing RasCAL-2:

Windows
-------
1. Download the installer (**\*.exe**) from the |releases| page
2. Run the installer and follow the wizard steps.

To run RaCAL-2, find it in the Windows Start menu or use the desktop shortcut.

Linux
-----
1. Download the installer (**\*.run**) from the |releases| page
2. Run the installer in a terminal as below and follow the prompts to continue
   (Use sudo to install in non-user directory).

   .. code-block:: console

       ./RasCAL-2-installer.run

To run RaCAL-2, run the following command from the terminal or navigate to the **bin** sub-directory
installer directory and run from there.

.. code-block:: console

    rascal

MacOS
-----
1. Download the installer (**\*.pkg**) from the |releases| page.
   Select the correct installer for your system architecture i.e arm64 for Apple silicon and x64 for intel.

2. Run the installer and follow the wizard steps.

Run the rascal app from the Applications directory, Launchpad, or Spotlight.
