Examples
========
A few examples are available in RasCAL-2 which demonstrate the supported model and calculation types. These
example projects are created from the |RAT examples| where more explanations about each example can be found.

To open an example:

.. image:: /images/load_examples.png
   :scale: 80
   :alt: Open example project
   :align: center

1. Click **File > Open Project** in the main menu to open the load project dialog.
2. In the dialog, click the Examples tab to reveal a list of examples and click on the desired entry in the
   examples list.

This will copy the selected example project to a temporary directory so the user does not modify the original, then
open the copied project in RasCAL-2. The following examples are available in the examples list:

1. **DSPC standard layers**: Reflectivity analysis of a floating bilayer of DSPC using standard layer model.
2. **DSPC custom layers**: Reflectivity analysis of a floating bilayer of DSPC using custom layer model.
3. **DSPC custom XY**: Reflectivity analysis of a floating bilayer of DSPC using custom XY model.
4. **domains standard layers**: Incoherent summing ('domains') from standard layer model.
5. **domains custom layers**: Incoherent summing ('domains') from custom layer model.
6. **domains custom XY**: Incoherent summing ('domains') from custom XY model.
7. **absorption**: Shows absorption (imaginary SLD) effect usually seen below the critical edge.
