Experimental Parameters
=======================
The experimental parameters tab contains 3 parameter tables for the Bulk Ins, Bulk Outs, and Scalefactors. These
tables have the columns and behaviours as the one described in the :doc:`Parameters <parameters>` tab.

.. image:: /images/experimental_parameters_tab.png
  :scale: 60
  :alt: Experimental Parameters in Project Window
  :align: center

Add and Remove Scalefactors
---------------------------
To add a new scalefactor (in edit mode):

.. image:: /images/scalefactors_editing.png
  :scale: 60
  :alt: Scalefactor table in Edit mode
  :align: center

1. Click the **Add new Scalefactor** button above the scalefactor table.
2. A new row entry will be added to the bottom of the table with an auto generated name. Modify the new entry by double
   clicking the cells and updating their values.

To remove a scalefactor (in edit mode), simply click the |delete| button on the specific row you want to remove.
